# TOM Post Effects (tompfx) — Гайд по использованию

Клиентская библиотека VFX-эффектов для Minecraft 26.1 (Fabric). Пост-обработка экрана (ping-pong FBO), тряска камеры, мировые оверлеи (тинт/обводка блоков), эффекты сущностей (тинт/обводка по UUID), ключевая анимация, привязки к миру и камере, датапаки, сетевые триггеры и публичный Java API.

- Версия гайда: 16 (см. [docs/CHANGELOG.md](CHANGELOG.md) для истории изменений)
- Мод: `tompfx-1.0.0.jar`, требует Fabric API

Файлы: `data/<namespace>/vfx/<имя>.json` и `data/<namespace>/vfx_curves/<имя>.json`. После правок — `/reload`. ID эффекта = `<namespace>:<имя>`. На выделенном сервере определения и кривые автоматически синхронизируются с клиентами при входе игрока и после `/reload`, поэтому кастомные (датапак) эффекты работают у всех игроков, а не только на сервере.

Изменяющие команды `/vfx play`, `/vfx playat`, `/vfx playentity`, `/vfx stop`, `/vfx set`, `/vfx key` требуют прав оператора (уровень gamemaster); `/vfx list` доступен всем.

---

## 1. Команды

| Команда | Описание |
|---|---|
| `/vfx play <эффект> [игроки]` | Запустить эффект (по умолчанию — себе). Автодополнение по Tab. |
| `/vfx playat <эффект> <x> <y> <z> [игроки]` | Запустить эффект с привязкой к мировым координатам: клиент перепривязывает пространственные биндинги (`screen_x/y`, `proximity`) к этой точке и использует её для позиций эффекта (для `block_tint`/`block_outline`). |
| `/vfx playentity <эффект> <цели>` | Запустить эффект на выбранных сущностях (селектор, напр. `@e[type=!player,distance=..10]`). Эффект шлётся игроку-исполнителю; цели передаются по UUID (до 16) и применяются к `entity_tint`/`entity_outline`. |
| `/vfx stop <эффект> [игроки]` | Остановить эффект (все его экземпляры). Эффекты с `fade_ticks > 0` плавно гаснут. |
| `/vfx set <эффект> {[параметр:значение],...} [игроки]` | Живой override параметров **играющего** эффекта, без перезапуска таймлайна. Если эффект не играет — запускается persistent-экземпляр с этими значениями. Tab ведёт по синтаксису: `{` → `[` → имя параметра → `:` значение → `]` → `,` (новая пара) или `}`. |
| `/vfx key <эффект> <параметр> <время> <значение> [easing] [игроки]` | Добавить/заменить ключевой кадр параметра играющего эффекта (время — тики от старта, easing — кривая к следующему кадру, Tab-автодополнение, включая имена кастомных кривых из датапака). |
| `/vfx list` | Список всех загруженных определений (встроенные + датапак). |

При запуске `/vfx stop` эффект удаляется мгновенно, если `fade_ticks` не задан или равен 0; иначе — плавное затухание к нейтральным значениям.

Повторный `/vfx play` того же эффекта **не заменяет** играющий экземпляр, а добавляет ещё один независимый (например, несколько вмятин на экране сразу). `/vfx stop <эффект>` останавливает все экземпляры; всего одновременно играют до 64 эффектов.

## 2. Типы эффектов

### 2.1 Пост-обработка экрана (шейдеры)

| Тип | Параметры | Описание |
|---|---|---|
| `chromatic_aberration` | `intensity` (0=выкл), `radius` (в пикселях) | Разделение RGB-каналов к краям экрана |
| `color_grade` | `saturation`, `contrast`, `brightness` (нейтраль = 1), `tint_r/g/b` (нейтраль = 1) | Цветокоррекция + оттенок |
| `distortion` | `amount`, `radius` | Barrel (`amount > 0`) / pincushion (`amount < 0`) искажение всего экрана |
| `dent` | `strength` (+Втягивание / −вытягивание), `radius` (в долях экрана), `center_x`, `center_y` (UV 0..1) | Локальная «вмятина» вокруг точки. Режим линии: `line_mode` (0/1) + `x0`,`y0`,`x1`,`y1` (UV 0..1) — вмятина вдоль отрезка; концы можно привязывать к миру через `bind: screen_x`/`screen_y`. |
| `gradient_map` | `from_r/g/b`, `to_r/g/b`, `intensity` | Маппинг яркости в двухцветный градиент |
| `posterize` | `strength` (0..1) | Постеризация с дизерингом |
| `blur` | `radius` (пиксели) | Двухпроходный адаптивный гауссов блюр |
| `pixelate` | `cell_size` (доля экрана) | Пикселизация |
| `hue_isolation` | `hue` (0..1), `tolerance`, `intensity` | Оставляет выбранный оттенок, остальное — Ч/Б |
| `vignette` | `intensity` (0..1), `color_r/g/b` (0..1) | Затемнение/окраска краёв экрана |
| `screen_flash` | `alpha` (0..1), `color_r/g/b` (0..1) | Полноэкранный цветной оверлей |
| `motion_blur` | `intensity` (0..1), `yaw_delta`, `pitch_delta` | Направленный блюр от скорости поворота камеры |
| `bloom` | `intensity` (0..1), `threshold` (0..1), `radius` (пиксели) | Свечение ярких участков экрана |
| `film_grain` | `intensity` (0..1), `size` (px зерна) | Анимированное плёночное зерно |
| `scanlines` | `intensity` (0..1), `line_count` (полос на 100px), `speed` (дрейф) | CRT-полосы, плывущие по экрану |
| `depth_of_field` | `intensity` (0..1), `focus_center` (UV Y), `focus_range` (полуширина резкости) | Экранный tilt-shift: резкая полоса, размытие от неё |
| `letterbox` | `height` (0..0.5), `color_r/g/b` | Кино-полосы сверху и снизу экрана |
| `invert` | `intensity` (0..1) | Инверсия цветов экрана |
| `vortex` | `strength` (радианы, ± = направление), `radius`, `center_x`, `center_y` (UV) | Закручивает пиксели воронкой вокруг точки |
| `fov_modifier` | `fov_delta` (градусы) | Изменение поля зрения (FOV) игрока |

### 2.2 Мировые оверлеи (геометрия модели блока)

| Тип | Параметры | Описание |
|---|---|---|
| `block_tint` | `color_r/g/b` (0..1), `alpha` (0..1), `through_blocks` (0/1, по умолч. 1) | Полупрозрачная заливка видимых граней модели блока; `through_blocks: 1` — видна сквозь другие блоки, `0` — перекрывается ими |
| `block_outline` | `color_r/g/b` (0..1), `alpha` (0..1), `width` (0..1), `shell` (0/1, по умолч. 0), `through_blocks` (0/1, по умолч. 0) | Контур блока в двух режимах: `shell: 0` — каждая грань модели выдавливается наружу вдоль нормали на `width/2` (контур не может закрыть блок); `shell: 1` — классическая расширенная оболочка задними гранями, обрезаемая глубиной самого блока (`width` = расширение). `through_blocks`: 1 — виден сквозь другие блоки, 0 — перекрывается ими |

Оба типа поддерживают список координат через поле `positions` (см. §3.1). Если список не задан, используется одна позиция из `params.pos_x/y/z` — она может быть константой, анимацией или привязкой к миру.

### 2.3 Эффекты сущностей (второй проход модели)

Эти типы нацелены на живых сущностей по UUID: клиент сохраняет UUID цели на render-state и во втором проходе перерисовывает модель сущности своим рендер-тайпом поверх оригинальной (ванильная текстура и шейдер не затрагиваются).

| Тип | Параметры | Описание |
|---|---|---|
| `entity_tint` | `color_r/g/b` (0..1), `alpha` (0..1), `texture` (0/1, по умолч. 1), `through_blocks` (0/1, по умолч. 1) | Заливка модели сущности цветом эффекта **с учётом её текстуры** (текстура используется как маска прозрачности, поэтому эффект повторяет силуэт, а не прямоугольник вокруг модели). `texture: 1` — перекрашивание текстуры цветом (texture × цвет, виден сам узор); `texture: 0` — сплошной цвет с текстурой только как маской. `through_blocks: 1` — виден сквозь стены, `0` — перекрывается ими |
| `entity_outline` | `color_r/g/b` (0..1), `alpha` (0..1), `width` (0..1, по умолч. 0.05), `through_blocks` (0/1, по умолч. 0) | Обводка силуэта по типу «перевёрнутого корпуса»: модель расширяется на `width` вокруг вертикального центра, остаются только задние грани — наружу выступает тонкий ободок. Текстура используется как маска, поэтому обводка повторяет контур текстуры (нет сплошного прямоугольника). `through_blocks: 1` — свечение видно сквозь стены (полный силуэт), `0` — перекрывается стенами |

Цели задаются через `/vfx playentity <эффект> <селектор>` или через Java API (см. §7): в пакете `tompfx:vfx_trigger` передаётся список UUID (до 16). Один эффект может нацеливаться сразу на несколько сущностей; на одной сущности могут одновременно висеть несколько эффектов. Если селектор выбирает больше 16 сущностей, эффект применяется только к первым 16 (лимит пакета); всего одновременно играют до 64 эффектов (`MAX_ACTIVE_EFFECTS`).

### 2.4 Прочее

| Тип | Параметры | Описание |
|---|---|---|
| `camera_shake` | `amplitude_x/y/z`, `yaw`, `pitch`, `roll` | Тряска камеры симплекс-шумом с плавной огибающей |
| `collection` | — (см. §5) | Не эффект: сценарий из нескольких эффектов с задержками |

## 3. Формат датапака

Файлы: `data/<namespace>/vfx/<имя>.json`. После правок — `/reload`. ID эффекта = `<namespace>:<имя>`.

```json
{
	"type": "dent",
	"duration": 60,
	"easing": "ease_out_cubic",
	"loop": false,
	"persistent": false,
	"fade_ticks": 10,
	"params": { "...": "..." },
	"sound": "minecraft:block.note_block.pling",
	"positions": [[8, 70, 8], [9, 70, 8]]
}
```

### 3.1 Поля определения

| Поле | Тип | По умолч. | Описание |
|---|---|---|---|
| `type` | строка | — (обязательно) | Тип эффекта из §2 |
| `duration` | int | 40 | Длительность в тиках (20 тиков = 1 сек). Для `loop` — период цикла. |
| `easing` | строка | `linear` | Кривая для параметров вида `start`→`end` |
| `loop` | bool | false | Зациклить анимацию: таймлайн проигрывается по кругу, эффект бесконечен до `/vfx stop`. |
| `persistent` | bool | false | Эффект бесконечен (значения параметров замирают на конечных), до `/vfx stop`. |
| `fade_ticks` | int | 10 для persistent/loop, иначе 0 | Плавное появление при play и затухание при stop. Затухание ведёт параметры к **нейтральным** значениям (brightness→1, radius→0 и т.д.; позиции не искажаются). |
| `params` | объект | — | Параметры эффекта (см. §3.2) |
| `effects` | массив | — | Дочерние эффекты для `collection` (см. §5) |
| `sound` | строка | — | ID звукового события, проигрываемого при старте эффекта на клиенте |
| `sound_pos` | массив `[x,y,z]` | — | Мировые координаты для позиционного воспроизведения звука (ванильная механика, как `/playsound ... x y z` — громче вблизи, тише вдали). Если не задан — звук играет лично игроку без привязки к кордам |
| `volume` | параметр (см. §3.2) | 1.0 | Громкость звука (зарезервированный параметр, может быть константой, анимацией, биндом или выражением) |
| `pitch` | параметр (см. §3.2) | 1.0 | Высота тона звука (зарезервированный параметр) |
| `positions` | массив `[x,y,z]` | — | Список мировых координат для `block_tint`/`block_outline`. Если не задан — используется `params.pos_x/y/z`. Для entity-эффектов не используется (цели задаются UUID). |

### 3.2 Способы задать параметр

```jsonc
"params": {
	// 1) Константа
	"radius": 4.0,

	// 2) Анимация от начала до конца длительности (с easing'ом определения)
	"intensity": { "start": 0.8, "end": 0.0 },

	// 3) Ключевые кадры (время — тики от старта, у каждого сегмента свой easing)
	"brightness": { "keyframes": [
		{ "time": 0,  "value": 0.8,  "easing": "ease_out_quad" },
		{ "time": 30, "value": 1.25, "easing": "ease_in_quad" },
		{ "time": 60, "value": 0.8 }
	] },

	// 4) Привязка к миру/камере (пересчитывается каждый кадр)
	"center_x": { "bind": "screen_x", "pos": [8, 80, 8] },
	"center_y": { "bind": "screen_y", "pos": [8, 80, 8] },
	"strength": { "bind": "proximity", "pos": [8, 80, 8], "range": 32, "scale": 0.9, "invert": false },

	// 5) Мультипликатор: база (keyframes/start-end/константа/привязка) × множитель.
	// Здесь вмятина анимируется ключевыми кадрами и дополнительно ослабляется по мере удаления от точки.
	"strength": {
		"keyframes": [ { "time": 0, "value": 0.8 }, { "time": 40, "value": 0.0 } ],
		"multiply": { "bind": "proximity", "pos": [8, 80, 8], "range": 64 }
	},

	// 6) Математическое выражение (компилируется в AST при создании экземпляра,
	//    оценивается каждый кадр). Переменные: t (тики от старта), x/y/z (координаты камеры),
	//    pi, e. Функции: sin, cos, abs, min, max, pow, sqrt, random() (0..1),
	//    noise(x,y,z) (simplex 3D, -1..1). random()/noise() уникальны для каждого экземпляра.
	"intensity": { "expr": "abs(sin(t * 0.1)) * 0.8 + random() * 0.2" }
}
```

Звук эффекта может иметь собственную громкость и высоту тона через зарезервированные параметры `volume`/`pitch` (константа, анимация, бинд или выражение). Значения читаются один раз на момент старта эффекта:

```jsonc
{
	"type": "screen_flash",
	"sound": "minecraft:block.note_block.pling",
	"params": {
		"alpha": 0.3,
		"volume": { "bind": "proximity", "pos": [8, 80, 8], "range": 32 },
		"pitch": 1.5
	}
}
```

Чтобы звук воспроизводился в мире на координатах (ванильная позиционная механика, как `/playsound ... x y z` — громче вблизи, тише вдали), задай `sound_pos`:

```jsonc
{
	"type": "screen_flash",
	"sound": "minecraft:block.note_block.pling",
	"sound_pos": [8, 80, 8],
	"params": {
		"volume": 1.0,
		"pitch": 1.2
	}
}
```

Без `sound_pos` звук играет лично игроку (без привязки к кордам). Позицию можно переопределить через API, передав `sound_pos_x/y/z` в оверрайды `sendEffect`.

### 3.3 Привязки к миру и камере

| `bind` | Значение | Описание |
|---|---|---|
| `screen_x` / `screen_y` | UV 0..1 (−scale, если точка за камерой) | Экранная позиция мировой точки `pos: [x,y,z]` — эффект «следует» за точкой |
| `proximity` | 0..1 (×scale) | 1 возле `pos`, плавно к 0 на расстоянии `range` (по умолч. 16). `invert: true` — наоборот (0 возле, 1 вдали). Позади камеры = 0 (если не `invert`). |
| `look` | 0..1 (×scale) | 1, когда камера смотрит ровно в направлении `yaw`/`pitch` (в градусах), плавно к 0 при угловом отклонении `range` (по умолч. 90°). `invert: true` — наоборот. |
| `camera_yaw_delta` | градусы/тик (×scale) | Изменение yaw камеры между кадрами |
| `camera_pitch_delta` | градусы/тик (×scale) | Изменение pitch камеры между кадрами |
| `health` | 0..1 (×scale) | Доля здоровья локального игрока (health / max). `invert: true` — растёт при падении HP. |
| `hunger` | 0..1 (×scale) | Доля сытости (food / 20) |
| `speed` | 0..1 (×scale) | Горизонтальная скорость (блоков/сек), нормализованная на `range` (по умолч. 5 = спринт) |
| `light_level` | 0..1 (×scale) | Освещённость в позиции игрока (block/sky light / 15) |
| `time_of_day` | 0..1 (×scale) | Доля суточного цикла (0 = рассвет) |

Пример — красная виньетка при низком HP:

```jsonc
"intensity": { "bind": "health", "invert": true, "scale": 0.9 }
```

Пример — блюр при спринте:

```jsonc
"radius": { "bind": "speed", "range": 6, "scale": 8 }
```

Опции: `pos` (для screen/proximity), `yaw`, `pitch` (для look), `range`, `scale` (по умолч. 1), `invert`.

Пример — dent-линия, приклеенная к двум мировым точкам (вмятина «прорезает» экран между ними):

```jsonc
"params": {
	"line_mode": 1,
	"strength": 0.8,
	"radius": 0.1,
	"x0": { "bind": "screen_x", "pos": [8, 80, 8] },
	"y0": { "bind": "screen_y", "pos": [8, 80, 8] },
	"x1": { "bind": "screen_x", "pos": [12, 80, 8] },
	"y1": { "bind": "screen_y", "pos": [12, 80, 8] }
}
```

Примеры:
- `tompfx_test:dent_world` — вмятина, приклеенная к координате `[8, 80, 8]`, сила падает до нуля в 32 блоках;
- `tompfx_test:blur_look` — блюр (радиус до 10), усиливающийся при взгляде на юг (yaw 0, pitch 0) и исчезающий при отклонении > 60°.

### 3.4 Easing'и

`linear`, `ease_in_quad`, `ease_out_quad`, `ease_in_out_quad`, `ease_in_cubic`, `ease_out_cubic`, `ease_in_out_cubic`, `ease_in_expo`, `ease_out_expo`, `smoothstep` (регистронезависимо, `-`/`_` равнозначны).

Помимо встроенных имён можно задавать свои кривые: именованным файлом в датапаке (`data/<namespace>/vfx_curves/<имя>.json` с массивом опорных точек `points`; опорные точки имеют вид `[t, v]`, `t` от 0 до 1) или инлайн-объектом с массивом `curve`:

```jsonc
"intensity": { "start": 0.0, "end": 1.0, "easing": { "curve": [[0, 0], [0.6, 0.9], [1, 1]] } }
```

Такое значение можно использовать в любом поле `easing` — определения эффекта, отдельного keyframe'а или дочернего эффекта коллекции.

## 4. Постоянные эффекты: вкл/выкл с анимацией

```json
{
	"type": "block_outline",
	"persistent": true,
	"fade_ticks": 15,
	"positions": [[8, 70, 8]],
	"params": { "width": 0.05, "color_r": 1.0, "color_g": 0.85, "color_b": 0.2, "alpha": 0.9 }
}
```

- `/vfx play` → плавное появление за `fade_ticks` (вес 0→1);
- `/vfx stop` → плавное исчезновение, затем эффект удаляется;
- для шейдерных эффектов вес смешивает параметры с нейтральными значениями (`VFXEffectType.neutralValue`);
- для оверлеев вес умножается на `alpha`.

## 4.1 Зацикливание

```json
{
	"type": "block_outline",
	"loop": true,
	"fade_ticks": 10,
	"duration": 40,
	"positions": [[8, 70, 8]],
	"params": {
		"width": 0.05,
		"color_r": 0.2, "color_g": 0.6, "color_b": 1.0,
		"alpha": { "keyframes": [
			{ "time": 0, "value": 0.15 },
			{ "time": 20, "value": 1.0 },
			{ "time": 40, "value": 0.15 }
		] }
	}
}
```

`loop` = эффект на всегда + таймлайн (включая keyframes и `start`/`end`) проигрывается по кругу с периодом `duration`. Останов — как у persistent (`fade_ticks`).

## 4.2 Эффект на сущности

```json
{
	"type": "entity_outline",
	"duration": 120,
	"fade_ticks": 10,
	"params": { "width": 0.06, "color_r": 1.0, "color_g": 0.85, "color_b": 0.2, "alpha": 1.0, "through_blocks": 0 }
}
```

Для тинта добавь `"texture": 1` (перекрашивание текстуры) или `"texture": 0` (сплошной цвет с текстурой как маской):

```json
{
	"type": "entity_tint",
	"duration": 120,
	"fade_ticks": 10,
	"params": { "color_r": 0.2, "color_g": 0.6, "color_b": 1.0, "alpha": 0.5, "texture": 1, "through_blocks": 0 }
}
```

Запуск на ближайших мобах (селектор выбирает цели, UUID отправляются клиенту):

```
/vfx playentity tompfx_test:test_entity_outline @e[type=!player,distance=..10]
```

То же самое из Java API — см. `VFXAPI.sendEffect(...)` с аргументом `List<UUID> entityUuids` в [docs/API.md](API.md).

## 5. Коллекции — несколько эффектов одной командой

```json
{
	"type": "collection",
	"effects": [
		{ "effect": "tompfx_test:marker_persistent", "delay": 0 },
		{ "effect": "tompfx_test:block_tint_demo", "delay": 10 },
		{ "effect": "tompfx_test:blur_grow", "delay": 20 },
		{ "effect": "tompfx_test:red_pulse", "delay": 40, "duration": 60 },
		{ "effect": "tompfx:chromatic_aberration", "delay": 55, "duration": 40, "params": { "intensity": 1.2 } }
	]
}
```

Поля дочернего эффекта: `effect` (ID, обязателен), `delay` (тики от запуска коллекции), `duration` (0 = по умолчанию определения, −1 = постоянный), `params` (только числа — переопределение констант), `easing`. Вложенность коллекций — до 4 уровней. `/vfx stop <коллекция>` отменяет ещё не запущенные дочерние; уже играющие останавливаются их собственным `/vfx stop`.

## 6. Встроенные эффекты (без датапака)

Пост-обработка: `tompfx:chromatic_aberration`, `tompfx:color_grade`, `tompfx:distortion`, `tompfx:dent`, `tompfx:gradient_map`, `tompfx:posterize`, `tompfx:blur`, `tompfx:pixelate`, `tompfx:hue_isolation`, `tompfx:vignette`, `tompfx:screen_flash`, `tompfx:motion_blur`, `tompfx:bloom`, `tompfx:film_grain`, `tompfx:scanlines`, `tompfx:depth_of_field`, `tompfx:letterbox`, `tompfx:invert`, `tompfx:vortex`.

Мировые оверлеи: `tompfx:block_tint`, `tompfx:block_outline`.

Эффекты сущностей: `tompfx:entity_tint`, `tompfx:entity_outline`.

Прочее: `tompfx:camera_shake`, `tompfx:fov_modifier`.

Все с анимацией затухания (40 тиков, кроме указанных), можно переопределять параметры коллекциями.

## Changelog

История изменений фич по версиям — **[docs/CHANGELOG.md](CHANGELOG.md)**.

Версия гайда: 16 — см. changelog ниже.

### v16
- Новые типы эффектов для сущностей: `entity_tint` (сплошная полупрозрачная заливка цветом эффекта) и `entity_outline` (обводка силуэта по типу «перевёрнутого корпуса», толщина `width`). Цели задаются по UUID.
- Новая команда `/vfx playentity <effect> <targets>` — запускает эффект на сущностях, выбранных селектором (до 16 UUID).
- Оба типа поддерживают `through_blocks`: 0 — эффект скрывается за стенами, 1 — виден сквозь них.

### v15
- Новый способ задать параметр — математическое выражение `"expr"` (переменные `t`/`x`/`y`/`z`/`pi`/`e`, функции `sin`/`cos`/`abs`/`min`/`max`/`pow`/`sqrt`/`random`/`noise`). Компилируется один раз, оценивается каждый кадр; `random()`/`noise()` уникальны для каждого экземпляра.
- Тряска камеры (`camera_shake`) теперь уникальна для каждого вызова (per-instance seed).

### v14
- Изменяющие команды `/vfx` (`play`, `playat`, `stop`, `set`, `key`) теперь требуют прав оператора; `/vfx list` открыт всем.
- Ужесточение защиты клиента от враждебного/битого сервера: лимиты на размеры сетевых пакетов (параметры эффекта, синк определений/кривых), проверка версии пакета `vfx_sync`, кап длительности эффекта от сервера, валидация instance id при остановке.

### v13
- Дапак-VFX-эффекты и кривые синхронизируются с клиентами выделенного сервера (пакет `tompfx:vfx_sync` при входе и после `/reload`) — кастомные эффекты теперь проигрываются у игроков на dedicated-сервере, как в одиночной игре.

### v12
- `sendEffect` принимает прямую мировую позицию — без хака с `pos_x/y/z` (клиент сразу перепривязывает пространственные биндинги к точке).
- Свои кривые easing: файлы `data/<ns>/vfx_curves/<имя>.json` или инлайн-объект `{ "curve": [[t,v],...] }` в любом поле `easing`.
- Мультипликатор параметра: `"параметр": { keyframes/start-end/константа/привязка + "multiply": { "bind": "proximity", ... } }` — итоговое значение = база × множитель (например, анимированная вмятина, затухающая по мере удаления от точки).
- `VFXAPI.playEffectId(...)` возвращает id экземпляра, `VFXAPI.stopEffect(long)` останавливает один конкретный экземпляр; `sendStop(player, effectId, instanceId)` — по сети.
- Сетевой протокол версии 4: пакет несёт опциональную позицию и instance id.
